AI Real-Time Virtual Try-On Web App
Designed & Developed by Udara Dissanayake

An interactive, browser-based Augmented Reality (AR) Virtual Fitting Room powered by MediaPipe Pose Detection and HTML5 Canvas API. This application allows users to virtually try on different designer t-shirts in real-time directly through their webcam without sending any video data to external servers.

✨ Key Features
Real-Time Body Landmark Tracking: Uses lightweight AI pose estimation to detect shoulder positioning, angle, and torso dimensions with sub-second latency.

Dynamic Clothes Fitting & Scaling: Automatically adjusts the shirt's scale, perspective, and tilt angle in real time as the user moves.

Interactive Wardrobe Selector: Switch instantly between multiple designer t-shirt styles (Classic Black, Pure White, Sport Red, Navy Blue).

Custom Outfit Upload: Supports uploading custom transparent PNG garments for instant live testing.

Client-Side & Privacy-First: All computer vision processing runs locally in the browser — no webcam streams are stored or uploaded.

Zero Backend / Serverless: Ready for instant static hosting on GitHub Pages.

🛠️ Tech Stack
Frontend: HTML5, CSS3 (Modern Dark UI), Vanilla JavaScript (ES6+)

AI / Computer Vision: Google MediaPipe Pose Detection Model

Rendering Engine: HTML5 2D Canvas API

Hosting: GitHub Pages
